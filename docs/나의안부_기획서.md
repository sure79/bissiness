## 0. 결론

**차별화 한 문장: 삼성과 유플러스의 안부 서비스는 "지켜보는 사람"을 위한 도구다. 나의 안부는 "혼자 사는 사람 본인"을 위한 도구다.**

- **삼성 스마트싱스 패밀리 케어**: 가족이 부모님의 활동을 매일 본다. 갤럭시와 삼성 가전이 기반이다.
- **유플러스**: 한전과 함께 지자체가 고른 대상자의 전력·통신 데이터를 분석해 복지 담당자에게 알린다. 본인이 설치하는 앱이 없다.
- **휴대폰가족보호 (통신 3사 부가서비스)**: 가족이 위치와 휴대폰 미사용을 확인한다.

세 서비스 모두 "지켜볼 가족"이나 "대상자로 뽑아 줄 기관"이 있어야 작동한다. 고독사 최대 위험군인 중장년 남성 1인가구에는 둘 다 없는 경우가 많다. 그리고 이들은 누가 자신을 지켜보는 것을 싫어한다.

그래서 나의 안부는 다섯 가지 원칙으로 만든다.

| 원칙 | 의미 | 경쟁 서비스와 차이 |
|---|---|---|
| 1. 내가 켠다 | 설치, 연락처, 기준 시간, 공개 범위를 본인이 정한다 | 가족이나 기관이 켜는 구조와 반대 |
| 2. 평소엔 아무도 안 본다 | 지킴이는 평소 활동 기록을 볼 수 없다. 이상할 때만 연락이 간다 | 가족이 매일 활동을 보는 구조와 반대 |
| 3. 안 눌러도 된다 | 휴대폰 사용으로 자동 체크인한다. 버튼은 보조다 | 중국 앱은 매일 눌러야 하고, 이틀을 놓쳐야 알린다 |
| 4. 연락할 사람이 없어도 된다 | 지인·형제 다음에 관리사무소·임대인, 계약 지역은 주민센터까지 | 가족이 있다는 전제와 반대 |
| 5. 죽음 대신 오늘 | "고독사"라는 말을 쓰지 않는다. "오늘도 이상 무"를 쌓는다 | 낙인 없는 이름과 톤 |

**출시 순서 제안: 나의 안부를 먼저 내고, 가족용 하루안부는 같은 엔진으로 이어서 낸다.**
- 국내에는 같은 개념의 앱이 아직 보이지 않는다. 반면 가족 돌봄은 삼성이 선점했다.
- 폰 한 대와 연락처 문자만 있으면 된다. 부모님 폰과 자녀 폰을 묶는 과정이 없어서 MVP가 더 단순하다.
- 2026년 1월 중국 앱 화제로 국내 언론에 이미 개념이 소개됐다.

## 1. 왜 중장년 남성 1인가구인가

| 지표 | 수치 | 출처 |
|---|---|---|
| 고독사 사망자 (2024) | 3,924명, 남성 약 82% | 보건복지부 2024년도 고독사 발생 실태조사 |
| 60대 남성 / 50대 남성 비중 | 27.8% / 26.2% | 같은 조사 |
| 최초 발견자 (2024) | 임대인 43.1%, 가족 26.6%, 지인 7.1% | 같은 조사 |
| 최초 발견자 변화 (2020→2024) | 임대인 28.4%→43.1%, 가족 34.8%→26.6%, 지인 14.5%→7.1% | 같은 조사 |
| 고독사 중 기초생활수급자 (2023) | 5명 중 2명 이상 | 2023년도 실태조사 보도 |
| 1인 가구 중 아플 때 도움받을 사람이 있다 | 68.9% | 국가데이터처, 2025 통계로 보는 1인 가구 |
| 1인 가구 중 외롭다 | 48.9% | 같은 자료 |
| 서울 1인 가구 중 가사·돌봄 도움이 필요할 때 연락할 대상 없음 | 56.6% | 서울시 1인가구 실태 (2024 보도) |

**시사점 세 가지**
1. **가족과 지인이 발견하는 비율은 해마다 줄고, 임대인이 발견하는 비율은 늘었다.** 연락망을 가족과 지인으로만 짜면 현실과 맞지 않는다. 관리사무소와 임대인을 연락망에 넣을 수 있어야 한다.
2. **1인 가구 셋 중 하나는 아플 때 도와줄 사람이 없다.** 연락처를 다 채우지 못하는 사용자도 쓸 수 있어야 한다.
3. **공공 안전망은 수급자와 고령자 중심이다.** 일하는 50대 비수급자는 대상자 선정에서 빠지기 쉽다. 이들에게는 스스로 가입하는 도구가 필요하다.

**가져올 것**: 앱 설치가 필요 없는 메신저 체크인, 사람이 전화로 확인하는 마지막 단계, 창업 이야기가 만드는 신뢰.

## 4. 포지셔닝

**메시지: "혼자 살아도, 이상 무."**
- 돌봄 앱이 아니라 **혼자 사는 사람의 안전벨트**로 소개한다. 블랙박스나 보험처럼 만일을 위해 켜 두는 것이다.
- 소비자 화면과 광고에는 "고독사", "독거", "돌봄 대상"이라는 말을 쓰지 않는다. 기관 제안서에서만 쓴다.

**해자 (복제 방어)**
1. **자동 감지 엔진**: 갤럭시 신호 수집과 오탐 조정 노하우다. 버튼 앱은 금방 베끼지만 이것은 쉽게 베끼지 못한다.
2. **연락망 운영**: 지킴이 수락, 담당 지정, 관리인 단계, 출입 정보 공개 규칙이다.
3. **기관 계약**: 지자체와 임대 관리 쪽 레퍼런스는 복제할 수 없다.
4. **신뢰**: 평소엔 아무도 안 본다는 원칙과 최소 수집이다.

## 6. 제품 설계

### 6-1. 첫 화면
- 가운데 큰 버튼: **이상 무!**
- 그 아래 상태 한 줄: "오늘 07:12 자동 확인됨"
- 연속 기록: "이상 무 37일째"
- 지킴이: "지킴이 2명 대기 중". 지킴이 쪽에서는 내 기록이 보이지 않는다는 안내를 함께 둔다.

### 6-2. 체크인 방식
| 방식 | 갤럭시 | 아이폰 | 비고 |
|---|---|---|---|
| 자동 | 잠금 해제, 걸음, 충전기 연결 | 걸음 기록, 늦게 도착 | 하루안부 v2 엔진 공용 |
| 버튼 | 앱, 홈 위젯, 알림 버튼 | 앱, 홈 위젯, 알림 버튼 | |
| 카카오톡 | 정해진 시각에 오는 카톡 메시지의 "이상 무" 버튼 | 같음 | 알림톡 정책 확인 필요. 앱이 싫은 사람의 진입로 |

- **기준 시간**: 12, 24, 48시간 중 선택한다. 기본은 24시간이다.
- **취침 시간**: 23시부터 07시까지는 지킴이에게 연락하지 않고 본인에게만 알린다. 야간에도 연락받을지는 선택할 수 있다.

### 6-3. 지킴이 연락망
- **초대와 수락**: 문자나 카톡으로 초대 링크를 보낸다. 지킴이는 역할 설명을 읽고 수락해야 등록된다. 지킴이에게는 앱이 필요 없다.
- **순서**: 지킴이 1, 지킴이 2, 관리인 순서로 연락한다. 앞사람이 "제가 확인할게요"를 누르면 다음 사람에게는 누가 확인 중인지만 알린다.
- **지킴이가 없을 때 쓰는 대체 연락망**
  1. **관리사무소나 임대인**: 본인이 연락처를 넣고 동의한다. 마지막 단계에서만 연락한다.
  2. **주민센터**: 계약한 지자체 주민만 해당하며, 본인 동의가 필요하다.
  3. **안부 매니저**: 유료다. 상담원이 전화로 확인하고, 연락이 안 되면 112에 신고를 요청한다. 외부 콜센터와 제휴한 뒤에 연다.
- **지킴이 부담 관리**: 지킴이 화면에 지난 1년 동안 받은 연락 횟수를 보여 준다. 지킴이는 언제든 그만둘 수 있다. 오탐이 반복되면 본인에게 기준 시간 조정을 권한다.

### 6-4. 경보 흐름 (기본 24시간)
```
[T]       마지막 신호 + 기준 시간 → 본인 폰 알림 (소리, 3회 반복) "이상 무 확인이 필요해요"
[T+30분]  응답 없음 → 지킴이 1에게 카톡, 실패하면 문자
[T+60분]  담당 지정 없음 → 지킴이 2
[T+90분]  담당 지정 없음 → 관리인 (등록한 경우)
[T+120분] 미해결 → 전체 재알림. 담당 지킴이에게 주소, 비상 정보, 출입 정보 공개. 112·119 신고 안내
```
- 지킴이가 "연락됐어요"를 누르면 종료하고 모두에게 알린다.
- 본인이 언제든 "이상 무"를 누르면 즉시 종료하고 지킴이들에게 "괜찮으시대요"를 보낸다.

### 6-5. 지킴이가 받는 메시지 예시
초대:
```
[이상무] 김철수님이 회원님을 지킴이로 등록하고 싶어 합니다.
평소에는 아무 연락도 가지 않습니다.
김철수님이 하루 넘게 소식이 없을 때만 알려 드립니다.
수락하기: https://...
```
1차 경보:
```
[이상무] 김철수님이 24시간 넘게 휴대폰 사용이 없고, 확인 알림에도 답이 없습니다.
전화 한 통 부탁드립니다. 010-0000-0000
제가 확인할게요 / 연락됐어요: https://...
```
마지막 단계:
```
[이상무] 아직 김철수님과 연락이 되지 않았습니다.
위급하다고 판단되면 112 또는 119에 신고해 주세요.
주소와 비상 정보 보기 (지킴이 본인 확인 후 열림): https://...
```
- 문자 본문에는 주소를 넣지 않는다. 링크는 지킴이 휴대폰 번호 인증을 거쳐야 열린다.

### 6-6. 비상 정보와 출입 정보 금고
- **비상 정보**: 주소, 지병, 복용약, 혈액형, 반려동물, "꼭 알려야 할 사람"(평소 연락이 끊긴 자녀 등).
- **출입 정보**: 공동현관과 도어락 비밀번호. 기기에서 암호화해 저장하고, 마지막 단계에서 담당 지킴이 1명에게만 1회 공개한다. 공개하면 기록을 남기고 본인에게도 알리며, 비밀번호를 바꾸라고 안내한다.
- 경보가 없으면 누구도 볼 수 없다. 회사 직원도 볼 수 없게 설계한다.

### 6-7. 외출 모드와 타이머 안부
- **외출 모드**: 출장, 여행, 입원 기간에는 경보를 쉰다.
- **타이머 안부**: "오후 5시까지 하산 예정, 북한산 OO 코스"처럼 적어 둔다. 정한 시각까지 "무사 도착"을 누르지 않으면 행선지 메모와 함께 지킴이에게 알린다.
- 위치 공유는 넣지 않는다. 넣으려면 위치기반서비스사업 신고를 먼저 해야 한다.

### 6-8. 매일 열 이유
- **오늘의 한 줄**: 체크인하면 날씨, 어제 걸음 수, 오늘의 운세 한 줄을 보여 준다. 운세는 운영자의 철학관 강점을 살린 것이며 끌 수 있다.
- **안부 짝꿍**: 서로 동의한 지인 1~3명과 "이상 무" 도장을 주고받는다. 이 경우에만 서로의 체크인이 보인다. 외로움을 덜어 주는 장치다.
- **이야기하고 싶을 때**: 자살예방 상담전화 109와, 서울 거주자에게는 외로움안녕120을 안내한다. 앱이 우울감을 진단하거나 판정하지 않고, 버튼으로 연결만 한다.

| 후보 | 장점 | 단점 |
|---|---|---|
| **이상무** (추천) | 군대 점호의 "이상 무!"라서 중장년 남성에게 익숙하다. 죽음을 말하지 않는 유머가 있고, "이 상무님"으로도 읽히는 재미가 있다 | 사람 이름처럼 보일 수 있다 |
| 생존신고 | SNS에서 흔히 쓰는 말이라 2030 바이럴에 강하다 | 중장년에게는 가벼워 보일 수 있다 |

- 키프리스 상표 검색과 앱스토어 동일 이름 확인이 필요하다.
- **톤 규칙**: 담백하고 약간의 유머를 쓴다. 불안을 키우는 문구는 쓰지 않는다. "혼자 사는 남자의 안전벨트" 정도까지만 쓴다.

## 8. 수익 모델 (가격은 가설)

| 상품 | 가격 | 내용 |
|---|---|---|
| 기본 | 무료 | 자동·버튼 체크인, 지킴이 2명, **경보 문자 무료**, 비상 정보 |
| 든든 | 월 1,900원 / 연 19,000원 | 지킴이 5명, 카톡 체크인, 출입 정보 금고, 타이머 안부, 짝꿍, 관리인 단계 |
| 선물 1년권 | 19,000원 | 자녀나 형제가 결제하고, 설정은 본인이 한다 |
| 안부 매니저 | 월 9,900원 안팎 | 상담원 전화 확인, 112 신고 요청. 제휴 이후 |
| 기관용 | 대상자당 연 과금 | 지자체·임대 관리 담당자 화면. 스마트플러그보다 낮은 비용 |

- **원칙: 안전 기능은 돈으로 막지 않는다.** 경보 문자는 무료 사용자도 받는다. 경보는 드물어서 원가가 작고, 이 원칙 자체가 신뢰를 만드는 마케팅이 된다.
- **현실적인 기대**: 개인 유료 전환율은 낮을 것이다. 매출의 중심은 선물과 기관 계약이고, 개인 사용자는 레퍼런스와 확산을 만든다.
- **임대인 시장**: 일본은 임대인용 고독사 보험이 흔하고, 나고야시는 고령 1인가구가 입주하면 집주인의 고독사 보험료를 대신 낸다. 국내에서는 2017년 DB손해보험 상품 정도만 확인된다. 임대 관리업체 제휴는 2년 차 이후의 가설로 둔다.
